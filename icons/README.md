# Menstruation Tracker icon concepts

Three original, locally generated app-icon concepts are included. Each concept has a 512×512 transparent-edge PNG and a multi-resolution Windows ICO.

- `bloom-petal`: soft floral mark, warm lavender/rose palette.
- `lunar-cycle`: crescent and orbital cycle motif, misty blue palette.
- `heartleaf`: heart and leaf motif, calm sage palette.

These are selectable design directions, not a final approved brand mark. The EXE currently retains its compiled Win32 window icon; rebuilding with a selected ICO is a separate release step.
